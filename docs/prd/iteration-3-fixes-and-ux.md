## P1. 버그 (기능 결함 — 최우선)

### B1. 로그인 상태가 유지되지 않음 (설정 화면 진입 시 로그아웃됨)
- **증상**: 로그인 후 설정 화면에 들어가면 로그아웃 상태가 된다. 로그인이 세션 동안 유지되지 않는다.
- **기대**: 로그인 상태는 **앱 전역(세션 단위)로 유지**되어야 하며, 설정 화면 등 다른 화면으로 이동/복귀해도 로그인 계정이 그대로 유지된다.
- **추정 원인(개발 검증 필요)**: 로그인/계정 상태가 화면 이동 시 재생성되는 ViewModel에 담겨 있거나, 오버레이 네비게이션 시 공유 세션이 아닌 새 인스턴스를 참조. → 로그인 상태를 앱 스코프 단일 소스(예: AppShellViewModel/세션 서비스, 싱글턴)로 승격하고 설정·상단바가 같은 소스를 읽도록.

### B2. 설정을 변경·저장해도 실제로 적용되지 않음
- **증상**: 설정 화면에서 옵션을 바꾸고 저장했으나 반영되지 않는다.
- **기대**: 저장 시 INI에 **정확히 영속**되고(재시작 후 복원), 가능하면 **현재 세션에도 즉시 반영**(촬영 컷수·카운트다운·거울모드·로컬저장 등 다음 촬영/동작에 실제 사용).
- **개발 검증 필요**: SaveSettings가 (a) INI에 실제로 기록되는지, (b) 런타임에서 설정을 소비하는 서비스/VM이 갱신값을 읽는지(시작 시 1회만 읽고 캐시해서 안 먹히는지) 확인 후 수정.

## P2. UI / UX 개선

### U1. 설정 화면 레이아웃 정리
- 현재 설정창 **배열이 이상함**. 항목 정렬·그룹핑·간격·라벨/컨트롤 정렬을 정돈해 읽기 쉽고 깔끔하게. 라이트 테마 A 디자인 시스템 토큰 사용.

### U2. ComboBox 디자인 개선
- 설정의 ComboBox가 투박함 → 라이트 테마에 맞게 **더 세련되게** 재스타일(라운드·보더·화살표 아이콘·hover/focus·드롭다운 항목 스타일). Controls.xaml에 ComboBox 스타일/템플릿 추가.

### U3. 로그인 화면 Enter 키 → 로그인
- 로그인 화면에서 **Enter 키 입력 시 로그인 버튼 클릭으로 동작**(비밀번호 입력 후 엔터). `IsDefault=True` 또는 KeyBinding으로.

### U4. 카메라 로딩 대기 표시
- 카메라 초기화/로딩까지 시간이 걸림 → 그동안 **로딩(웨이팅) 표시**(스피너/오버레이 + "카메라 준비 중" 등 안내). 프리뷰 준비되면 사라짐.

### U5. [바로 촬영] 버튼을 셔터 버튼으로
- 현재 [바로 촬영] 텍스트 버튼을 **셔터 모양(원형 셔터 아이콘) 버튼**으로 교체.
- 셔터 **위 또는 아래에 작게 "바로 촬영"** 라벨을 두어 기능을 직관적으로 이해하게.

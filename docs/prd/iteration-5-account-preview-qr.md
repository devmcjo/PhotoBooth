## P1. 버그

### B6. QR 전송 OFF인데도 전송 시도 → 실패 팝업
- **증상**: 촬영 종료 시 "전송에 실패했습니다. 네트워크 또는 Firebase 설정을 확인해주세요." 팝업이 여전히 뜬다. (설정에서 **QR 전송 토글은 OFF** 상태 — 스크린샷 확인.)
- **기대**: `EnableQrDelivery=false`면 **업로드·QR 시도 자체를 하지 않음**(팝업 없음, 로컬 저장만/완료로 진행). 설정값이 실제로 존중되는지 확인(it3 B2와 연관 — 저장/적용 경로).
- **참고**: QR ON인데 Storage(Blaze 미전환) 불가한 경우의 실패는 별개 — 이번엔 **off 존중**이 핵심. (Blaze는 사용자 보류 상태.)

### B7. 컷 선택/프리뷰 이미지가 슬롯과 다른 크기·크롭으로 표시 (WYSIWYG 파손)
- **증상**: 프레임 컷 선택 화면에서 이미지 프리뷰가 **슬롯과 다른 크기**로 보인다.
- **기대(PRD §F1/§F36)**: 카메라에서 보이는 모든 사진(**라이브 프리뷰·촬영 순간·컷 선택 썸네일·최종 합성**)이 **슬롯에 배치될 것과 동일한 종횡비로 중앙 크롭되어** 동일하게 보여야 한다(WYSIWYG). 슬롯 종횡비(it4 B4의 4:3/3:4/1:1 선택 반영)에 맞춰 프리뷰/썸네일도 크롭. 늘이기(stretch) 아님.

## P2. 설계 변경 (사용자 확정)

### B8. 촬영 종료 후 자동 로그아웃 제거 — 로그인 유지
- **확정**: 촬영 세션 종료 후에도 **로그인 유지**. 로그아웃은 **계정 메뉴에서 수동** 또는 **유휴 타임아웃** 시에만.
- **변경 대상**: it3에서 세션완료(Done→Home) 시 `clearUser:true`였던 것을 **`clearUser:false`로**(로그인 보존). 유휴 타임아웃 로그아웃 정책은 유지(무인 보호). 세션 데이터(촬영분) 초기화는 그대로.
- ⚠️ PRD §F8/§10·결정 #16/#30의 "세션 종료 후 게스트 복귀" 원안을 이 결정으로 갱신.

## P3. 계정/설정 구조 개편

### C1. 설정 페이지에서 계정 기능 제거
- 설정 페이지(앱 설정)에서 **비밀번호 변경**·**관리자 계정 생성** 섹션을 **제거**. 설정 페이지 = 앱 설정(AppSettings)만.

### C2. 계정 기능을 로그인(계정) 버튼의 메뉴 → 전용 페이지로
- 좌상단 로그인/계정 버튼 메뉴에서 항목 선택 시 **해당 기능 전용 페이지만 노출**:
  - 로그아웃
  - 비밀번호 변경 (신 비번 2회 확인)
  - (power = admin/manager) 사용자 관리 / 계정 생성 (역할 규칙: manager→user, admin→manager도)
- 각 항목은 자기 페이지만 보여주고, 설정 페이지와 분리.

## P4. UI/UX

### U7. 설정 페이지 레이아웃 재수정 (라벨 잘림 + PC 친화)
- **증상(스크린샷)**: 라벨이 잘림("촬영 컷 =", "컷당 카ᶕ", "카메라 ᶕ", "표시 ᶕ"), 카드가 좁고 중앙 정렬된 모바일풍.
- **기대**: 라벨이 **잘리지 않도록** 충분한 폭 + 값 컨트롤과 정렬. **PC(데스크톱) 친화** 레이아웃(적정 너비·정렬·밀도). 라이트 테마 토큰 유지. `setting_ng.png` 참조.

### U8. 로그인 페이지 진입 시 아이디 입력창 자동 포커스
- 로그인 버튼 눌러 로그인 페이지 진입 시 **포커스가 바로 아이디(ID) 텍스트박스**에 잡히게.

### F1. 프레임 편집기 슬롯 크기 조절 슬라이더
- 프레임 만들 때 **슬롯 크기 조절** 추가. **배치된 모든 슬롯이 동일 크기로 일괄 조정**.
- 기본 100% 기준 **70%~130% 조절 슬라이더** + 현재 **% 값 표시 칸**.
- (it4 B4 종횡비 선택과 공존 — 비율 유지한 채 크기 스케일.)

## 1. 네비게이션 진입점 (홈/상단 바)

### 1.1 좌측 상단 — 로그인 버튼
- 홈(및 적절한 화면)의 **좌측 상단에 로그인 버튼**을 둔다.
- 누르면 **로그인 페이지로 이동**한다.
- 로그인 상태에서는 이 영역이 계정 허브 역할(로그아웃·비밀번호 변경 진입 등, PRD §F8 "계정 화면" 취지)을 겸한다.
- 기존 PRD의 "좌상단 3초 롱프레스" 관리자 진입과 충돌하지 않게 통합/정리한다(명시적 버튼 우선, 롱프레스는 보조 또는 폐지 — 설계에서 판단하고 근거 기록).

### 1.2 우측 상단 — 설정 버튼
- **우측 상단에 설정 버튼**을 둔다. 누르면 **설정 페이지**로 이동한다.

---

## 2. 설정 페이지 (현재 전무 — 최우선 결함)

> **현재 옵션을 수정할 수 있는 UI가 하나도 없다. 이는 큰 오류다.** `AppSettings`(INI) 항목을 UI로 노출·수정 가능해야 한다.

### 2.1 게스트(비로그인)도 수정 가능한 설정
- 게스트도 설정 페이지에 진입해 **앱 설정을 수정**할 수 있어야 한다.
- 예: 거울모드(좌우반전), 로컬 저장 모드(saveLocalCopy), 그 외 `AppSettings`의 촬영/표시 관련 옵션 전반.
- 수정 결과는 INI에 저장되어 재시작 시 복원(기존 PRD #38).

### 2.2 로그인 사용자(user 이상) 추가 기능
- **비밀번호 변경**: 로그인 이후 자기 비밀번호를 변경할 수 있어야 한다. **변경할 비밀번호는 두 번 입력받아 일치 확인**(confirm) 후 적용.

### 2.3 관리자(admin/manager) 추가 기능 — 설정 페이지 내 노출
- **사용자 계정 생성**:
  - `manager`/`admin`은 **일반 사용자(user) 계정을 생성**할 수 있다.
  - **`admin`은 `manager` 계정도 생성**할 수 있다(manager는 manager를 만들 수 없다 — PRD §F8 역할 규칙: admin만 manager 지정).
- 기존 PRD의 사용자 관리(목록·삭제·비밀번호 초기화, power 전용)와 일관되게 배치.
- 로그인 역할에 따라 관리자 섹션이 **조건부로 표시**된다(게스트/user에게는 숨김).

---

## 3. 촬영 진입 흐름

- 홈에서 **[촬영하기]를 누르면 바로 촬영(관련) 페이지로 이동**한다.
- **로그인 상태가 아니면 별도 선택 없이 그냥 게스트 모드로 진행**한다(게스트=기본 프레임만).
- 즉, 기존 "로그인/게스트 선택 화면"을 강제로 거치지 않는다 — 커스텀 프레임이 필요할 때만 로그인(§1.1 버튼)으로 유도.

## 4. UI 전면 재디자인 (가장 중요)

> 현재 UI는 **투박하고 올드하다("대학교 1학년 첫 프로젝트 수준")**. 2026년 트렌드에 맞는 구성으로 전면 재설계한다.

### 4.1 목표
- **사용자 친화적 · 심플 · 세련**된 UI.
- 색 조화, 폰트, 버튼 모양, 간격, 아이콘, 애니메이션 등 **모든 디자인 요소를 전면 수정**.
- 키오스크/터치 환경 적합(큰 터치 타깃, 명확한 가시성). 가로/세로 레이아웃 모두(PRD #20).

### 4.2 레퍼런스 조사 (설계 단계에서 반드시 수행)
- 벤치마크: `E:\Study\photobooth\Example\BM.pdf` ("나만의 네컷") UI 재확인.
- 상용 서비스 UI 조사: **포토이즘(Photoism), 포토그레이(Photogray), 인생네컷** 등 현재 운영 중인 셀프 포토부스 앱/키오스크의 화면 구성·색·타이포·인터랙션 패턴.
- 조사 결과를 근거로 **디자인 시스템**(색 팔레트, 타이포 스케일, 컴포넌트 스타일, spacing, 상태별 스타일)을 정의하고 설계 문서에 명시.

### 4.3 산출 기대
- WPF `ResourceDictionary` 기반의 재사용 가능한 디자인 시스템(색→브러시→스타일→템플릿 계층).
- 전 화면(홈/로그인/설정/프레임 선택/편집기/촬영 안내/프리뷰/카운트다운/컷 선택/결과/QR/완료/관리자 등)에 일관 적용.
- MVVM 순수성 유지(코드비하인드 최소화), 성능(가상화·Freezable) 고려.

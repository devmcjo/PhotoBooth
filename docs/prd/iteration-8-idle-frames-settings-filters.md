## 1. 계정 / 유휴 타임아웃

### A1. 유휴 타임아웃 재설계 — 로그아웃 절대 금지
- **현재**: 무동작 시 홈 복귀 + 로그아웃(clearUser). → **이 로그아웃을 제거한다.**
- **요구**:
  - 프레임 선택 등 어느 화면이든 **2분 무동작** 시 팝업: "**XX초 후 메인 화면으로 돌아갑니다**" — **10초부터 카운트다운**.
  - 팝업 버튼 2개: **[이어서 진행하기]**(취소, 현재 화면 유지·타이머 리셋) / **[메인 화면으로]**(즉시 홈).
  - 카운트다운이 0이 되면 **메인(홈) 화면으로 복귀하되 로그아웃은 절대 하지 않는다.**
  - **로그아웃은 오직 로그아웃 버튼으로만.** (유휴·세션완료·화면이동 어떤 경우에도 자동 로그아웃 금지.) 이유: 로그아웃되면 새 프레임 생성·선택이 불가해짐.
- 세션 만료(장시간)는 추후 고려 — 이번엔 미구현.

### (참고) SSO
- 카카오/구글 로그인 등 SSO 연동은 **추후 개발**. 이번 이터레이션에서 구현하지 않는다.

## 2. 프레임 저장 구조 재설계

### A2. 소유 주체별 저장 위치 (하이브리드: 파워=DB+로컬캐시 / user=로컬전용)
- **파워 관리자(admin/manager) 생성 프레임**:
  - **DB(Firestore+Storage)에 저장** + **모든 로그인 계정에서 공용 사용**.
  - **매번 다운로드 금지**: 로컬 `Frame/` 폴더에 해당 프레임이 있으면 그걸 사용, **없을 때만** DB에서 로컬로 1회 다운로드(캐시). DB 접근·서버 부하 최소화.
- **일반 관리자(user) 생성 프레임**:
  - **로컬에만 저장**(DB 미업로드).
  - 파워 프레임과 **이름 충돌 방지**: 파일명을 **`<계정명>_<프레임이름>.png`** 로 저장.
- **슬롯 정보 저장 방식**:
  - 프레임 이미지와 **동일 이름의 슬롯 설정 파일**(예: `<name>.slots`, 기존 `Frame/*.slots` 관례 활용)에 슬롯 개수·위치·크기·종횡비를 저장. 로컬 프레임은 이미지+슬롯파일 쌍으로 관리.
  - (DB 프레임은 기존 Firestore 문서의 slots + Storage 이미지 유지; 로컬 캐시 시 슬롯 파일도 함께 생성.)
  - 최종 형식·확장자는 설계에서 확정(기존 `.slots` 포맷 재사용/정의).

### A3. 프레임 삭제 기능
- **프레임 선택 창**에서 **관리자(일반·파워 모두) 로그인 상태**일 때:
  - 각 프레임 카드 **우상단 X 버튼** 노출.
  - X 클릭 → **"삭제하시겠습니까?" 확인 팝업**.
  - **파워 관리자 로그인 시**: 팝업에 **"서버에서도 제거" 체크박스**(기본 **OFF**)도 함께 노출.
  - **OK** 누르면:
    - 항상 **로컬 파일 삭제**(이미지 + 슬롯 파일).
    - "서버에서도 제거" 체크 시(파워만) **DB에서도 해당 프레임 Delete**(Firestore 문서 + Storage 이미지).
  - 게스트/비관리자에게는 삭제 UI 미노출.

## 3. 설정 화면

### A4. 저장·닫기 버튼 상시 노출 (sticky)
- 설정 저장/닫기 버튼의 시인성 부족(스크롤해야 보임). → **스크롤과 무관하게 항상 보이는 고정 위치**(예: 설정 패널 하단 고정 바)로 배치.

### A5. QR 전송 OFF→ON 전환 시 세부 둘 다 자동 ON
- (it7에서 "사진·타임랩스 둘 다 끄면 QR off"는 구현됨.) 추가: **QR 전송이 OFF였다가 ON으로 켜질 때는 세부(사진/타임랩스)를 무조건 둘 다 ON**으로. 기본값 ON. 즉 개별 조절은 가능하되, QR off→on 재활성화 시 항상 둘 다 켜진 상태로 시작.

## 4. 카메라 / 이미지 처리

### A6. 이미지 필터 옵션 설정화 + 실제 처리
- 결과 화면 필터(원본 / 흑백 / 밝기 / (간단)뷰티 등)를 **설정 창에서 개별 on/off**(기본 **전부 ON**). QR처럼 각각 끌 수 있는 구조.
- **"원본"은 항상 존재 — 토글 불가(Disable 처리)**. 끌 수 없어야 함(원본은 기본 제공).
- 필터를 실제로 쓰려면 **이미지 처리(Image Processing) 기능 구현/검증 필요** — 흑백·밝기·간단 뷰티가 실제 결과에 적용되는지 확인·완성. 설정에서 켜진 필터만 결과 화면 필터 선택지로 노출.

### A7. 카메라 waiting UI를 "실사용 가능 시점"까지 유지
- (it5에서 카메라 로딩 스피너 추가됨.) 그러나 로딩 표시가 사라진 뒤에도 **카메라가 즉시 켜지지 않음**. → **카메라가 실제로 사용 가능(프리뷰가 실제로 나오는) 시점까지 waiting UI 유지**. "Ready" 판정을 실사용 가능까지로 강화(첫 프레임 수신 이후 안정적 프리뷰까지).

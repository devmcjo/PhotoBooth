## P1. 프레임 편집기 버그 (기능 결함 — 최우선)

### B3. 슬롯 좌표 계산 오류 (경계/매핑 버그)
- **증상**:
  - 슬롯을 **이미지 크기에 맞게 배치할 수 없음**.
  - **좌측**으로는 슬롯이 **이미지 경계를 벗어나게** 설정됨(왼쪽 클램프 실패).
  - **우측**으로는 슬롯이 **넘어가지지 않음**(오른쪽 끝까지 못 감/막힘).
- **추정 원인(개발 검증)**: 편집기 캔버스(화면) 좌표 ↔ 프레임 이미지 원본 좌표 변환이 잘못됨(스케일/오프셋). 경계 클램프가 이미지 실제 영역이 아니라 잘못된 기준(캔버스 크기·레터박스 여백 미반영 등)으로 계산되어 좌측 오버플로우/우측 도달 불가 발생.
- **기대**: 슬롯이 **프레임 이미지 영역 내에서 정확히** 좌우·상하 끝까지 배치 가능하고, 경계를 넘지 않음. 화면 표시 좌표와 저장되는 이미지 좌표가 일치(WYSIWYG). 이미지가 편집 영역에 레터박스로 표시될 경우 여백을 제외한 실제 이미지 영역 기준으로 클램프.

### B4. 슬롯 종횡비 선택 (현재 1:1 고정)
- **증상**: 슬롯 크기가 **1:1 고정**이라 다른 비율을 못 만듦.
- **기대**: 슬롯 종횡비를 **4:3 / 3:4 / 1:1** 중 선택 가능(슬롯 단위 또는 편집기 옵션). 선택한 비율로 슬롯 크기 조절 시 비율 유지. (캡처 크롭이 슬롯 종횡비를 따르므로 §F1/§F36과 일관되게 반영.)

### B5. 프레임 편집 중 자동 로그아웃 + 홈 이탈
- **증상**: 프레임 편집 창에서 **오래 두면 자동으로 로그아웃되며 기본(홈) 화면으로 나가짐**.
- **원인(추정)**: 유휴 타임아웃(IdleWatchdog)이 **편집 중에도 발동** → 세션 취소·홈 복귀 + (it3의 유휴 시 clearUser:true 정책으로) 로그아웃. 편집기가 사용자 활동(드래그·클릭)을 유휴 타이머 리셋으로 반영하지 않거나, 편집 화면이 유휴 타임아웃 대상에서 제외되지 않음.
- **기대**: 프레임 편집 중에는 자동 로그아웃/이탈이 일어나지 않아야 함. **편집 중 사용자 활동은 유휴 타이머를 리셋**하거나, **편집기 화면은 유휴 타임아웃에서 제외**. (무인 키오스크 보호가 필요하면 편집기에서는 더 긴 타임아웃 + 이탈 시에도 로그인 보존을 고려 — 설계에서 결정.)

## P2. UI

### U6. 설정 페이지 PC 친화적으로 변경
- **증상**: 현재 설정 페이지가 **너무 모바일 친화적**(큰 터치 타깃·세로 나열 느낌).
- **기대**: **PC(데스크톱) 친화적 설정 페이지**로 재구성 — 데스크톱 관례에 맞는 밀도(조밀한 행), 마우스 조작 기준, 표준 크기 컨트롤, 카테고리 그룹핑(필요 시 좌측 카테고리 내비 또는 섹션 구분). 키오스크 터치도 여전히 되되 데스크톱에서 자연스럽게. 라이트 테마 A 토큰 유지.
- 참고: it3에서 만든 2열+큰 터치 타깃 레이아웃(U1)을 데스크톱 지향으로 재조정하는 것.

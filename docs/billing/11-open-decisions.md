## 2. 항목별 상세

### D-01 🔴 QR 상품 모델

| 항목 | 내용 |
|------|------|
| 질문 | QR 과금을 ① 기간제 일일 정원 플랜 ② 총량 회수권(일 상한 포함) ③ 둘 다 중 무엇으로 파는가? |
| 왜 결정이 필요한가 | 요구 원문("하루 제한", "00시 초기화", "첫날 일할")은 ①을 지시하지만, ①만 두면 정원 초과 시 돈을 내고도 못 쓴다. 카탈로그 스키마·판정 함수·UI가 모두 이 선택에 달려 있다 |
| 선택지 | (a) 플랜만 (b) 회수권만 (c) **플랜 + 1일권 + 회수권 + 오버리지**(권장) |
| 권장 근거 | 상시 부스(30일 플랜)·성수기(1일권)·소량(회수권)의 수요가 모두 실재하고, 소비 우선순위([03 §2.1](./03-qr-daily-quota.md))로 한 엔진에서 처리 가능하다 |
| 결정 후 갱신 | [01 §4](./01-currency-catalog-and-pricing.md), [03 §2](./03-qr-daily-quota.md), [07 §3.1](./07-api-and-data-contract.md) |

### D-02 🔴 플랜 기간

| 항목 | 내용 |
|------|------|
| 질문 | 일일 정원 플랜의 기간은 며칠인가? |
| 왜 결정이 필요한가 | **같은 가격에서 기간이 30배 단가 차이를 만든다**([01 §4.2](./01-currency-catalog-and-pricing.md) 표). 30일 플랜에 제시 가격(85MC)을 쓰면 원가를 회수하지 못한다 |
| 선택지 | 7일 / **30일**(권장) / 무기한(✕ B7 위반) |
| 부수 결정 | 만료 기준 = `구매일 + N일`의 KST 24:00([03 §5.4 P3](./03-qr-daily-quota.md)) |

### D-03 🔴 MC 팩 가격표 · VAT

| 항목 | 내용 |
|------|------|
| 질문 | ① 팩 구성·가격 ② 제시 가격이 VAT **포함**인가 |
| 지적 사항 | 원안의 20·30MC는 할인 0%라 "대량 결제 유도" 의도가 작동하지 않는다. 최대 팩(100MC)은 중형 부스 월 사용을 커버하지 못한다([01 §5.4](./01-currency-catalog-and-pricing.md)) |
| 권장 | 대안 A: 10/1,000 · 30/2,800 · 50/4,500 · 100/8,500 · **300/24,000**, VAT 포함 |

### D-04 🔴 QR 플랜 가격표

| 항목 | 내용 |
|------|------|
| 질문 | 정원별 MC 가격 |
| 지적 사항 | **원안에 단가 역전 2건**: Q30(1.17 MC/정원1) < Q50(1.70). 플랜 누적을 허용하므로 "Q30 두 개가 Q50보다 싸고 정원도 크다"는 모순이 생긴다([01 §4.1](./01-currency-catalog-and-pricing.md)) |
| 권장 | 30일: 70/180/270/480/850MC · 1일권: 20/50/75/135/240MC (둘 다 단가 엄격 감소) |
| 확정 절차 | dry-run 실측 원가 → 하한 → 부스 인터뷰 상한 → 확정([01 §8](./01-currency-catalog-and-pricing.md)) |

| 왜 차단인가 | 지급 없이 강제하면 **기존 유료 없는 계정의 QR이 전면 중단**된다([03 §3.2](./03-qr-daily-quota.md)) |
